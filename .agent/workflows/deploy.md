# Deploying your Portfolio

To deploy this portfolio, follow these steps:

1. **Verify Files**: Ensure `index.html`, `style.css`, and `script.js` are in your root directory.
2. **Local Preview**:
   // turbo
   Run `npx serve .` to preview it locally.
3. **Choose a Platform**:
   - **Vercel/Netlify**: Just drop the folder or connect your GitHub repo.
   - **GitHub Pages**: Go to repository settings -> Pages -> Select 'main' branch and root folder.
4. **Customization**:
   - Update `script.js` with your personal data.
   - Replace the `project-thumb` background with real images.
